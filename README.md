# AnyCard
Want to play any card game on any computer?  Me, too!

Step one is to write a library (<name goes here>) for tracking cards during a game.  I'm still doing this part and it's the most boring part, hopefully.

Step two is to hack a few games together using the library.

The order of the following steps is uncertain and variable:
- Develop a DSL to allow anyone to write their own games
- Develop a UI to allow people to play games together

## History
This is a renamed successor to xcge following a new strategy, after learning how to actually build something like this.
